# Handoff: Codex, Antigravity CLI, and Claude Code in Home Manager

## Goal and scope

Install `codex`, `agy`, and `claude` on Dancer and Kellanved (NixOS, x86_64-linux) and Crokus (standalone Home Manager, aarch64-darwin). Keep Pi working as it does today. Share one source for portable skills, one for global instructions, one for MCP registrations, and one pinned EGM bundle. Integrate RTK with each client's native hooks. Do not share credentials, permission grants, session state, or Pi-only extensions.

All three homes import `homes/profiles/development/default.nix`. The existing `pkgs.llm-agents` overlay supplies all the CLIs and RTK on both platforms; Claude and RTK are already installed via the shared development profile. Do not add a second package for either or use a vendor installer. Avoid updating the Home Manager or llm-agents pin as part of the base change.
