# Handoff: Codex, Antigravity CLI, and Claude Code in Home Manager

## Goal and scope

The host homes select their additional CLI harnesses; Pi and `~/.agents/skills` come from the common development profile on every host.

| Host | Managed CLI harnesses |
| --- | --- |
| Kellanved (NixOS) | Pi, Claude Code, Codex, Antigravity CLI |
| Crokus (standalone Home Manager on macOS) | Pi, Claude Code |
| Dancer (NixOS) | Pi, Codex, Antigravity CLI |

The following integration and rollout steps apply only to the harnesses selected on each host. Context, client-specific skills, MCP integration, activation and optional RTK hooks follow that selection. Disabling a harness stops managing it; it does not purge credentials, sessions, writable settings or other private state. After a switch, old Home Manager links may disappear; independently installed tools can remain. The matrix describes the repository configuration, not a confirmed deployment.

All three homes import `homes/profiles/development/default.nix`. The existing `pkgs.llm-agents` overlay supplies the CLIs and RTK. Do not add a second package or use a vendor installer. Keep global instructions, portable skills and MCP registrations shared, and keep permissions, credentials and Pi-only extensions separate. EGM remains planned, not installed.
